# Roundabout-3D Browser Game

This project is generated by BLACKBOXAI.

## What to do
1. Ensure these files exist in the project:
   - `public/level/` containing the extracted `rltng.rar` OBJ assets (including `.obj`, and any `.mtl` + textures).
   - `public/cars/` containing a car model in GLB/GLTF format (recommended: `LowPolyCars.glb`).

2. Run a local server:
   - `npm install`
   - `npm run dev`

3. Open the shown URL.

## Notes
- The Web app uses Three.js + GLTFLoader.
- OBJ loading is supported via `OBJLoader` + `MTLLoader`.
